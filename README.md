# Nova-ai
✦ Nova AI Studio

Личный ИИ-ассистент для программирования: чат, агент со сборкой проектов, управление ПК и доступ в интернет. Работает на твоём компьютере, без лимитов и без подписок.

Возможности

Чат — история диалогов, блоки кода с кнопкой копирования, ответы по шагам в реальном времени, кнопка «Стоп».
Выбор модели и усилия — любая модель из твоего Ollama или OpenAI-совместимого API. Усилие: быстро, среднее, высокое, максимум.
Кодинг-агент — пишет файлы, запускает команды, проверяет результат, исправляет ошибки и собирает проект в ZIP вместе с build.yml для GitHub Actions.

Управление ПК (Windows) — мышь, клавиатура, скриншоты, запуск программ, перенос, копирование и удаление файлов.
Интернет — поиск через DuckDuckGo и чтение веб-страниц.

Обучение — база знаний, которая подмешивается в каждый ответ; кнопка 👍 копит датасет train.jsonl для дообучения; кнопка «Создать Nova-Coder» делает отдельную кодерскую модель в Ollama.

Телефон — APK-приложение подключается к Nova на ПК по Wi-Fi: чат, интернет, код и файлы. Управление ПК с телефона отключено.
